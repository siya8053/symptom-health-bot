# 💊 Symptom Health Bot

> A smart, beginner-friendly symptom checker built with Flask.  
> Designed for students and office workers who want quick, clear health insights — without the information overload.
**Note:** This project was logic-designed by me. Code was AI-assisted, then understood and customized by me.
---

## 🤔 The Problem

When you feel unwell, searching for symptoms online often leads to confusing medical jargon or scary worst-case scenarios. This project offers a **calm, simple, and honest alternative** – just select what you’re feeling, and get possible conditions, causes, and precautions in plain language.

---

## ✨ Features

- ✅ **30+ common symptoms** to choose from (headache, fever, anxiety, fatigue, etc.)
- ✅ **Custom symptom input** – type anything not listed
- ✅ **Intelligent matching** – uses a symptom–condition knowledge base (Python dictionaries)
- ✅ **Clear output** – possible condition, probability estimate, causes, precautions
- ✅ **Clean, responsive UI** – works on desktop and mobile
- ✅ **Disclaimer included** – reminds users this is for educational purposes only
